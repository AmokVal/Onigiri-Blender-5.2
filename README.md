# Onigiri for Blender 5.2

Since the original Onigiri project was abandoned for Blender versions newer than 3.6, I decided to adapt the add-on to more recent versions of Blender so I could continue using it and take advantage of the latest improvements.

Feel free to use, modify, or build upon the code.

**Credits:** All credit for the original add-on goes to **nessaki**, its original creator and programmer. This project is an adaptation of their original work.
